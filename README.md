# Javafx-Tetris
A simple Tetris clone I made with javafx. Was solely made to see how hard it was to make a Tetris clone, as I had heard a lot of buzz about it.
After creating the basics and having a little more fun, I abandoned the project and moved on to other projects that gave me more freedom.
The game has a slight bug where blocks occaisionally clip inside of each other, however I had never found out about this, as I didn't do much bug testing, as I wasn't really trying to make a fun game, I was just being experimental with Tetris.
